      How to read this

      This is not return migration. The ACS only asks where you lived one year ago. Someone who grew up here, spent a decade elsewhere, and moved back last year is counted as arriving from outside.

      U.S. Census Bureau, American Community Survey, tables B07201, B07204, and B07001, via Census Reporter. 1-year estimates are used when the area is large enough; smaller places and all tracts use 5-year estimates. The Census does not publish arbitrary place-to-place flows. A destination/origin pair can be answered only when it matches a published bucket: same city, same county, same state, other state, or abroad. Tracts cannot be used as a same-tract origin. Margin of error is the ACS 90% confidence interval.
